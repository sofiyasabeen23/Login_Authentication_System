# Login Authentication System

A simple web-based authentication system that allows users to register, log in, and access a protected dashboard.

## Features

- User registration
- Login validation
- Password validation
- Protected dashboard
- Logout functionality
- Clean and responsive interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Register a new account and log in.

## Purpose

This project was created to practice form handling, validation, JavaScript, DOM manipulation, and basic authentication concepts.
